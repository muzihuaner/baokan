# 📰 快点电子报刊

一个简约、清爽的电子报刊聚合平台，为您提供无干扰的数字阅读体验。

## ✨ 功能特性

### 📚 丰富的报刊资源
- **国内报刊**：按地区分类，涵盖全国各省市主要报刊
- **国际报刊**：按国家分类，提供全球优质报刊资源
- **实时更新**：自动同步公开报刊内容

### 🎨 优雅的阅读体验
- **极简界面**：清爽设计，专注阅读内容
- **分类浏览**：清晰的地区/国家分组，快速定位
- **沉浸式阅读**：支持全屏模式，无干扰阅读环境
- **响应式设计**：适配各种设备屏幕

### 🚀 便捷功能
- **一键加载**：点击即可加载报刊内容
- **新标签页打开**：支持在新标签页中打开报刊
- **快速关闭**：轻松关闭当前阅读的报刊
- **平滑动画**：流畅的展开/收起动画效果

## 🚀 快速开始

### 在线访问

## 🛠️ 技术栈

- **前端框架**：原生 HTML5
- **样式框架**：Tailwind CSS
- **交互框架**：Alpine.js
- **数据存储**：JSON
- **部署**：GitHub Pages



## 📖 使用说明

1. **选择分类**：在顶部导航栏选择「国内」或「国外」
2. **展开分组**：点击地区/国家名称展开报刊列表
3. **阅读报刊**：点击报刊名称加载内容
4. **全屏阅读**：点击全屏按钮进入全屏模式
5. **新标签页**：点击新标签页按钮在外部打开
6. **关闭阅读**：点击关闭按钮返回报刊列表
