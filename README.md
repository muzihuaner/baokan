# 📰 快点电子报刊 - 在线看报系统

一个现代化的电子报刊在线阅读系统，提供全国各地主要报刊的便捷访问。

## ✨ 主要特性

### 🎨 现代化UI设计
- **Tailwind CSS框架**：采用最新的Tailwind CSS，提供现代化、响应式的用户界面
- **美观的卡片布局**：报刊以卡片形式展示，支持悬停效果和平滑过渡动画
- **渐变色彩搭配**：不同地区/国家使用不同的渐变色彩，提升视觉层次
- **响应式设计**：完美适配桌面、平板和移动设备

### 🔍 强大的搜索功能
- **实时搜索**：支持报刊名称和地区的实时搜索
- **智能匹配**：搜索结果高亮显示，快速定位目标报刊
- **搜索历史**：保留搜索状态，提升用户体验

### 🗂️ 分类浏览
- **国内报刊**：按省市分类，包含人民日报、光明日报等权威媒体
- **国外报刊**：按国家分类，涵盖纽约时报、BBC等国际知名媒体
- **标签切换**：便捷的标签切换，快速在国内外报刊间切换

### 🚀 性能优化
- **现代JavaScript**：使用ES6+语法，模块化代码结构
- **异步加载**：报刊数据异步加载，提升页面响应速度
- **加载状态**：友好的加载提示，提升用户体验
- **错误处理**：完善的错误处理机制

## 🛠️ 技术栈

- **前端框架**：原生JavaScript (ES6+)
- **CSS框架**：Tailwind CSS
- **数据格式**：JSON
- **图标**：Heroicons (SVG)

## 🚀 快速开始

1. **克隆项目**
   ```bash
   git clone [repository-url]
   cd baokan
   ```

2. **打开项目**
   - 直接在浏览器中打开 `index.html`
   - 或使用本地服务器运行

3. **开始使用**
   - 浏览国内外报刊
